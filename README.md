# AI-Based Algorithm Visualization and Intelligent Query Assistant System

An interactive web-based educational application that helps students understand sorting and searching algorithms through step-by-step visualization, execution statistics, algorithm comparison, and an AI-powered query assistant.

## 📌 Project Overview

Understanding algorithms only through theory and source code can be difficult for beginners. This project provides an interactive environment where users can visualize the execution of fundamental sorting and searching algorithms.

The system displays algorithm execution step by step and highlights comparisons, swaps, sorted elements, and search positions. It also provides animation controls, execution progress, performance statistics, algorithm comparison, and an AI-based query assistant that answers questions according to the selected algorithm and its current execution state.

## ✨ Features

- Step-by-step algorithm visualization
- Custom array input
- Random array generation
- Sorting algorithm visualization
- Searching algorithm visualization
- Comparisons and swaps tracking
- Execution progress tracking
- Start, Pause and Reset controls
- Adjustable animation speed
- Binary Search visualization with Left, Right and Middle positions
- Algorithm comparison
- AI-based query assistant
- Context-aware explanations based on the current visualization state

## 🔢 Algorithms Implemented

### Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Searching Algorithms

- Linear Search
- Binary Search

## 🎯 Conclusion

This project successfully demonstrates an interactive approach to learning fundamental sorting and searching algorithms through step-by-step visualization and intelligent assistance.

The system allows users to visualize algorithm execution, observe comparisons and swaps, track execution progress and statistics, compare algorithms, and interact with an AI-based query assistant for context-aware explanations.

By combining **algorithm visualization, interactive controls, performance information, and AI-based assistance**, the project provides a more engaging and beginner-friendly environment for understanding algorithmic concepts.
